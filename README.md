# Apadrinhamento MK

Landing page desenvolvida para divulgação de um projeto social de apadrinhamento, apresentando informações sobre a iniciativa, beneficiários e formas de contribuição.

## 🚀 Demonstração

🔗 https://apadrinhamentomk.netlify.app

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- Apresentação do projeto social
- Exibição dos beneficiários
- Layout responsivo
- Navegação intuitiva
- Interface leve e de fácil utilização

## 📂 Estrutura do projeto

```
Apadrinhamento-MK/
│
├── images/
├── index.html
├── script.js
├── style.css
└── README.md
```

## ▶️ Como executar

1. Clone este repositório.

```bash
git clone git@github.com:brunopessino/apadrinhamento-mk.git
```

2. Abra o arquivo `index.html` no navegador.
